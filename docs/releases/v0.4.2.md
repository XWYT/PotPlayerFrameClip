# PotPlayer FrameClip 0.4.2

本次更新改进原生右键菜单的桥接初始化与状态处理，减少 FrameClip 操作误落入“关于 PotPlayer”的情况。

## 修复

- 桥接初始化改用有超时限制的窗口消息，让不处理普通队列消息的播放器窗口也能完成连接。
- 每次打开右键菜单时重置上一次的选择状态，补充对窗口边框右键的处理。
- 保留 PotPlayer 原生菜单入口，不增加常驻轮询、额外后台进程或运行库。

## 升级

下载 `PotPlayerFrameClip-v0.4.2-Setup.exe` 和同名 `.sha256` 文件。等待任务结束，正常退出 PotPlayer 和 FrameClip 后再安装。升级保留设置、任务记录、素材分类映射和导出文件。

公开安装包不含 FFmpeg；可使用已有 FFmpeg/FFprobe，或安装后再配置。

## 验证

32/64 位桥接、九项菜单操作、100/150/200% 缩放、跨线程菜单来源，以及安装、升级回滚和卸载回归已通过。开发主机实测确认小空窗口和视频播放时可重复打开 FrameClip 设置。其他皮肤、混合 DPI 和长期使用仍需继续扩大覆盖。

## English

This update improves native menu bridge initialization and clears stale selections when a context menu opens, reducing cases where a FrameClip action falls through to About PotPlayer. Initialization uses a bounded sent-window message, and border right-clicks are now handled. The native menu entry remains unchanged; no persistent polling, extra background process or runtime dependency is added.

Finish jobs and close PotPlayer and FrameClip before installing `PotPlayerFrameClip-v0.4.2-Setup.exe`. Settings, job history, title mappings and exported files are preserved. The lightweight installer requires a separately configured FFmpeg/FFprobe pair.

Validation covers x86/x64 bridges, all nine actions at three scaling levels, cross-thread context sources and install/upgrade/rollback/uninstall. Repeated settings actions passed on the development host with both an empty player window and video playback. Additional skins, physical mixed-DPI and long-duration coverage remain limited.
