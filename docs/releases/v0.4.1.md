# PotPlayer FrameClip 0.4.1 正式版

0.4.1 将 0.4.0 预览版的界面、后台任务和 GPU 优先处理作为正式版本发布，并修复本轮复查发现的托盘菜单生命周期问题。原 0.4.0 预览版标签及安装包保持不变。

## 修复

- 外观或语言刷新不再销毁正在处理点击事件的托盘菜单，避免 WinForms 后续收尾逻辑访问已释放的 ContextMenuStrip。菜单由托盘持有并复用，不增加轮询或额外后台进程。
- 新增重复点击、菜单关闭后重开、语言刷新及任务按钮在不同缩放比例下的回归检查。

## 功能

- 直接从源文件采集无损静帧、多格式片段，支持多种 HDR/SDR 色彩空间。
- 原生设置与任务界面、进度反馈、并行导出、独立截图和可调整的多屏提醒位置。
- GPU 优先解码与 CPU 回退，保留所选图片精度、编辑编码及色彩处理流程。
- 安装、升级和卸载统一界面，升级保留配置，失败时回退。

## 安装与升级

下载 `PotPlayerFrameClip-v0.4.1-Setup.exe` 和同名 `.sha256` 文件，安装前核对校验值。先完成任务，再正常退出 PotPlayer 和 FrameClip；桥接 DLL 不能在播放器运行时替换。默认保留设置、任务记录和导出素材。安装包未进行商业代码签名，请确认来源，不要关闭系统安全防护。

公开轻量包不含 FFmpeg，可以使用已有 FFmpeg/FFprobe，或安装后再配置；未配置时截图和导出不可用。Full 包仍不公开，须先完成对应源码、构建配方和依赖许可归档。

## 验证范围

正式版不表示所有硬件都已完成实机验收。NVIDIA 开发主机已进行实际媒体/GPU 对照；Intel/AMD 当前以调度策略覆盖为主，尚缺实机验证。不同皮肤、物理混合 DPI 和长时间使用仍需扩大覆盖。自动化界面测试在非输入桌面运行，不切换用户桌面。

GPU 主要加速解码，不代表全链路 GPU 渲染，也不保证短任务更快。HDR 原图保留源传递函数，SDR 副本不替代原图；Dolby Vision 动态元数据不会烘焙到图片或精确转码片段。

## English

0.4.1 is the stable release of the redesigned native interface, background jobs and GPU-preferred decoding introduced in 0.4.0. It fixes tray-menu lifetime during appearance or language refresh: the popup is reused rather than disposed inside a click callback before WinForms finishes teardown. Repeated click/reopen, localization and scaled job-action regressions were added.

Download the lightweight installer and its SHA-256 file. Finish jobs and close PotPlayer and FrameClip before upgrading. Existing settings and exported media are preserved by default. FFmpeg/FFprobe must be configured separately; the Full offline package remains withheld pending corresponding-source and license archival.

NVIDIA media comparisons and automated native bridge, UI and maintenance checks cover the development host. Intel/AMD real devices, additional skins, physical mixed-DPI and long-duration coverage remain limited. GPU decoding is not end-to-end GPU rendering or a speed guarantee. The 0.4.0 preview tag and assets are unchanged.
