# Third-party notices

## FFmpeg and FFprobe

PotPlayer FrameClip invokes ffmpeg.exe and ffprobe.exe as separate external programs. The lightweight installer does not include them. The optional Full offline candidate includes a pinned BtbN LGPLv3 shared Win64 build, installed only when selected. Its license and provenance accompany the binaries under tools/ffmpeg/<version>/.

The pinned archive/version/SHA256 are recorded in installer/ffmpeg-manifest.json. FrameClip does not modify these binaries. Shared DLLs remain separate, and users may select a compatible replacement build in Settings. No system PATH, driver or global FFmpeg installation is changed. ffplay, development headers and import libraries are not installed.

PUBLIC DISTRIBUTION GATE: before publishing the Full candidate, archive and provide the exact corresponding FFmpeg and linked-library sources, pinned build recipes, and all required dependency notices. A short-lived upstream binary URL alone does not satisfy this release gate. The local Full build is for development validation until that review is completed; it must not be uploaded automatically by release scripts.

FFmpeg builds may use LGPL, GPL, or additional terms depending on their configuration. Review the selected build before redistribution:

- https://ffmpeg.org/download.html
- https://ffmpeg.org/legal.html

## GPU processing dependencies

GPU decoding reuses the selected FFmpeg build (CUDA, D3D11VA, QSV, DXVA2), Windows DXGI and
the installed graphics driver. FrameClip does not install a CUDA Toolkit or graphics drivers.
The optional FFmpeg build can contain VPL, AMF, libplacebo and other enabled components as recorded by its version configuration; FrameClip does not invoke them outside its existing hardware decode paths. QSV requires suitable Intel
drivers/runtime already available to FFmpeg; FrameClip does not install them.
See [GPU processing](docs/gpu-processing.md)
for the supported paths, benchmark limitations and primary references.

## Lucide icons

The native UI embeds rasterized Lucide icons from `lucide-static` 0.468.0.
The build-only renderer is `scripts/render-icons.cjs`; no JavaScript icon runtime
is shipped. The ISC license and inherited Feather notice are retained in
`assets/LUCIDE-LICENSE` and included in the installed application.

- Source: https://github.com/lucide-icons/lucide

## README artwork

The dot-matrix banners are project artwork generated by `scripts/render-banner.py`.
The images contain rasterized text, not font files. No font is distributed with
the application or the banners. The renderer accepts a locally installed font.
